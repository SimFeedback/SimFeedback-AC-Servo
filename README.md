# SimFeedback-AC-Servo

## SFX-100 — Open-Source Motion Sim Platform

SimFeedback is PC software that receives telemetry from racing and flight simulations
(iRacing, Assetto Corsa, Project Cars, MSFS, ...) and translates it into motion cues.
The motion commands are sent to an Arduino-based microcontroller, which drives four
closed-loop AC servo actuators (SFX-100).

This repository contains everything you need to build your own SFX-100 motion rig:
the linear actuator design, the electronics, the firmware, and the SimFeedback software.
Use it as it is — no registration, no sponsor, no donation required.
